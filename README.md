Fullstack E-handel

En fullstack-webbutik byggd med React, TypeScript, Node.js och Express.

## Funktioner

- Produktvisning, sökning och paginering
- Kundvagn för gäster och inloggade användare
- Autentisering med Supabase
- Kassa och betalningar med Stripe
- Orderhantering och verifiering av betalningsstatus
- Stripe-webhooks för betalningsbekräftelse

## Teknikstack

- **Frontend:** React, TypeScript, Tailwind CSS
- **Backend:** Node.js, Express
- **Databas och autentisering:** Supabase, PostgreSQL
- **Betalningar:** Stripe
- **Driftsättning:** Vercel (frontend), Render (backend)

## Om projektet

Projektet visar kunskaper inom fullstackutveckling, REST API:er, databashantering, autentisering och betalningsintegrationer.
